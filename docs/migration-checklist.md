## Evidence boundary

Final functional run: 70 unit tests passed, including real host schema validation when DEVICEDOCK_TEST_HOST is set. Packaged actual-host integration validates five bundles, MCP definitions, queue-level power fence, owned power/bridge signal settings, unsupported transport behavior and full cleanup. Real headless Chromium tests validate FFT/cursor interactions, serial-event alignment, CSV/analysis/durable IDB, source-scoped library and rebuilt Worker/WASM; generated and legacy-format fixture patches decode byte-exact through an independent pinned native decoder. No screenshots or physical devices are used.

## Explicit implementation boundaries

- Native BLE/SPP are compiled host capabilities and remain optional on unsupported builds/platforms, as in the original. The actual current host includes the drivers and provider UI; plugin code does not duplicate their ownership.
- Typed IndexedDB blocks replace OPFS-compressed cold storage. The user-facing disk budget, rolling/stop policy, recovery and bounded writer are implemented; journals have an explicit 2 GB maximum and 20,000-block metadata bound. Large exports are explicit 200k-sample segments, and archive loading previews the last two million samples. Full disk CSV remains accessible by advancing segment offset. This backend choice trades compression for atomic journals.
- Long mode retains statistics, not waveforms. It reports observed-sample integration and never invents samples through gaps. Serial event anchors are live receive-clock alignment and are bounded with the retained waveform; offline CSV has no invented historical serial events.
- The patch provider retains the accepted bounded 4 MB input / 8 MB output / 256 MiB worker contract. Larger library/raw original images can be stored/transferred; patch generation rejects inputs beyond that explicit limit.
- Remote-source readiness requires the accepted root branch and matching release assets to be publicly reachable. The catalog's presence in this tree is not evidence of publication.
